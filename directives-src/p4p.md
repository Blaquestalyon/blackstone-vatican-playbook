### WBS: P4.P.1.1
:: SUMMARY
Monitor EU and Vatican implementing statutes and publications on a standing basis. An external trigger the whole EU-channel timing depends on.
:: DIRECTIVE
**STANDING / external trigger — not fully controllable, critical path.** Vatican and EU rule changes can open or gate the bank-channel route. You cannot control when they publish, so you must watch continuously and react fast.

**Actions**
1. Identify the specific sources to monitor: relevant EU regulatory publications and Vatican/Holy See implementing statutes affecting external-manager access and Catholic-institutional investment.
2. Set a standing monitoring cadence with named responsibility, so nothing is missed.
3. When a relevant statute or publication appears, assess its impact on the channel strategy and trigger the dependent routing decision (P5.U.2).
4. Keep a dated log of what was published and what it changed.

**Deliverable:** a live monitoring process with a dated statute/publication log.

**Done when:** monitoring is running continuously with clear escalation on relevant changes. This item stays active rather than closing once.

### WBS: P4.P.2.1
:: SUMMARY
Identify EU banks with Vatican / Catholic institutional adjacency. Find the banks that already sit close to the target capital.
:: DIRECTIVE
The bank channel is a route into IOR/Vatican-adjacent capital. Start by finding banks with genuine Catholic-institutional relationships.

**Actions**
1. Identify EU banks and private banks that serve Vatican, IOR, or Catholic-institutional clients or run Catholic-values mandates.
2. Note each bank's relevant relationships and external-manager activity.
3. Produce a candidate list for profiling (P4.P.2.2).

**Deliverable:** a candidate list of Catholic-adjacent EU banks.

**Done when:** the candidate banks are identified with their relevant adjacency noted.

### WBS: P4.P.2.2
:: SUMMARY
Profile each bank for external-manager channel fit. Assess which banks can actually onboard the fund as an external manager.
:: DIRECTIVE
Not every adjacent bank runs an external-manager program the fund can join. Profile for real fit.

**Actions**
1. For each candidate bank, profile its external-manager channel: how it selects managers, its criteria and minimums, and its process.
2. Assess fit against the fund's profile and the values mandate.
3. Rank the banks by channel fit and access value; this list feeds the per-bank applications (P4.R.1).

**Deliverable:** a ranked profile of each bank's external-manager channel fit.

**Done when:** every candidate bank is profiled and ranked, defining the application targets.

### WBS: P1.D.1.1
:: SUMMARY
Determine registration eligibility, threshold, and jurisdiction for the adviser. Get the regulatory status right before filing anything.
:: DIRECTIVE
Registration status drives what you must file and where. Settle it with counsel first.

**Actions**
1. With counsel, determine whether the adviser registers with the SEC or at the state level, based on assets under management, client types, and the exemption thresholds in force.
2. Confirm the home jurisdiction and any notice-filing states.
3. Document the eligibility conclusion and the resulting filing obligations.

**Deliverable:** a documented registration determination (SEC vs state, thresholds, jurisdictions).

**Done when:** the registration path is fixed and agreed with counsel.

> Thresholds and exemptions change and depend on Kate's specific AUM and client base. Confirm the current rule with counsel rather than relying on a remembered number.

### WBS: P1.D.1.2
:: SUMMARY
Draft Form ADV Parts 1, 2A, and 2B. This is the core registration filing and public disclosure document.
:: DIRECTIVE
Form ADV is the adviser's public face to regulators and to diligence teams. Draft it accurately and consistently with everything else.

**Actions**
1. Draft Part 1 (regulatory data), Part 2A (the firm brochure: services, fees, strategy, conflicts, disciplinary history), and Part 2B (the brochure supplement covering key personnel including Kate's background).
2. Make the strategy, fee, and screening descriptions consistent with the IMA, the screening methodology, and the marketing package. Diligence teams cross-check these.
3. Have counsel review the full draft.

**Deliverable:** review-ready Form ADV Parts 1, 2A, 2B.

**Done when:** the ADV is drafted, internally consistent, and counsel-reviewed, ready for Kate's attestation and filing.

### WBS: P1.D.1.3
:: SUMMARY
Build the compliance manual and code of ethics. The written program regulators and gatekeepers expect an adviser to run.
:: DIRECTIVE
This is the operating compliance framework. Gatekeeper operational due diligence will ask to see it.

**Actions**
1. Draft a compliance manual covering the required adviser policies: personal trading, conflicts, best execution, valuation, marketing/advertising, recordkeeping, privacy, business continuity, and oversight responsibilities.
2. Draft the code of ethics, including personal-trading pre-clearance and reporting.
3. Designate the chief compliance officer and define the review calendar.
4. Align the manual with the GIPS P&P manual and the AML program so there are no contradictions.

**Deliverable:** a compliance manual and code of ethics.

**Done when:** both are complete, consistent with the other programs, and adopted.

### WBS: P1.D.2.1

Draft AML/KYC policies and CIP procedures. Anti-money-laundering and know-your-customer controls that institutional and Vatican counterparties require.

**Done when:** the written program is complete and consistent with custody and compliance requirements.

### WBS: P1.D.3.1
:: SUMMARY
Determine the EU marketing route: AIFMD NPPR, MiFID, or reverse solicitation. This is the longest pole in Phase 1 and it gates state selection.
:: DIRECTIVE
**LONGEST POLE.** The EU access route decision governs everything downstream in EU registration and gates the Phase 4 EU work. Resolve it early and deliberately with specialist EU counsel.

**Actions**
1. With EU counsel, evaluate the realistic routes to reach EU/Vatican-adjacent investors: AIFMD National Private Placement Regime (NPPR) notifications, a MiFID top-up/relationship, or reliance on genuine reverse solicitation.
2. Weigh cost, timeline, and the number of member states each route practically supports, against where the target capital actually sits.
3. Choose the route and document the rationale; this decision constrains state selection (P1.D.3.2).

**Deliverable:** a documented EU access-route decision.

**Done when:** the route is chosen with counsel and recorded, unblocking member-state selection.

> Reverse solicitation is narrow and easily lost if the fund actively markets. Do not treat it as a default; confirm the boundaries with EU counsel before relying on it.

### WBS: P1.D.3.2
:: SUMMARY
Select the target EU member states for registration/notification. This enumerates the per-state work that follows and gates the EU milestone.
:: DIRECTIVE
**Enumerator.** The states chosen here define the dossiers, counsel, and filings below, and they gate the Phase 4 EU gate (M9). Choose based on where the target investors are, not on completeness.

**Actions**
1. Using the chosen route (P1.D.3.1), identify which member states host the target institutional and Vatican-adjacent capital.
2. Prioritize states by access value versus registration cost and time.
3. Produce the final list of states to register/notify in; this list drives P1.D.3.3 through P1.D.3.6.

**Deliverable:** a prioritized list of target EU member states.

**Done when:** the state list is fixed, defining the scope of the per-state EU work.

### WBS: P1.D.3.3
:: SUMMARY
Engage EU counsel per selected member state. Local expertise for each jurisdiction's filing.
:: DIRECTIVE
**LONGEST POLE.** Each member state has its own regulator and process; secure competent local coverage.

**Actions**

2. Confirm scope, fees, and timelines per state.
3. Set up a single coordination point so the states progress in parallel, not serially.

**Deliverable:** engaged EU counsel covering every selected state.

**Done when:** each target state has counsel engaged and a timeline.

### WBS: P1.D.3.4
:: SUMMARY
Prepare the registration/notification dossier for each selected member state. One dossier per state.
:: DIRECTIVE
**LONGEST POLE.** This splits into one dossier per state selected in P1.D.3.2. Standardize the core, localize the rest.

**Actions**
1. Build a master dossier of common materials (adviser documents, disclosures, the fund's proof stack) that every state reuses.
2. For each state, add the locally required forms, translations, and disclosures per local counsel.
3. Track dossier status per state on one tracker so nothing stalls unseen.

**Deliverable:** a completed registration/notification dossier for each target state.

**Done when:** every target state has a filing-ready dossier awaiting Kate's signature (P1.D.3.5).

### WBS: P1.D.3.6
:: SUMMARY
Track approvals and respond to regulator queries per member state. A standing watch item until every state clears.
:: DIRECTIVE

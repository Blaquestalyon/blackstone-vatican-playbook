### WBS: P5.T.1.1
:: SUMMARY
Research the Vatican IC mandate framework and award criteria. Understand exactly what the buyer is buying and how it decides.
:: DIRECTIVE
Phase 5 is the endgame: winning the Vatican allocation. Start by understanding the mandate framework in depth.

**Actions**
1. Research the Vatican Investment Committee's mandate framework: what mandates it awards, its investment objectives and constraints, and its stated values requirements.
2. Document the award criteria and the decision process, including who influences and who decides.
3. Note any Catholic-values or ethical requirements the fund must demonstrably meet.

**Deliverable:** a documented understanding of the mandate framework and award criteria.

**Done when:** the mandate framework and how it is awarded are clearly understood and recorded.

### WBS: P5.T.1.2
:: SUMMARY
Map the required proposal components. Know every element the proposal must contain before drafting.
:: DIRECTIVE
Turn the framework into a concrete components checklist.

**Actions**
1. From the mandate framework, list every required proposal component (strategy, values alignment, track record, operations, terms, and any Vatican-specific exhibits).
2. Map each component to the source material already built (M8 package, DDQ, methodology, verification, audit).
3. Flag any gap where a required component does not yet exist.

**Deliverable:** a proposal components checklist mapped to source materials.

**Done when:** every required component is identified and sourced, with gaps flagged for the eligibility assessment.

### WBS: P5.T.1.3
:: SUMMARY
Assess the fund against Vatican IC eligibility/award criteria and produce a gap-and-remediation list. A hard gate before submission.
:: DIRECTIVE
**HARD GATE before Vatican submission.** Do not deliver a proposal the fund cannot support. Test eligibility honestly first.

**Actions**
1. Assess the fund against every Vatican IC minimum and award criterion from P5.T.1.1.
2. Produce a gap-and-remediation list: what is met, what falls short, and how each shortfall can be closed.
3. Quantify remediation effort and timing so the go/no-go decision is informed.

**Deliverable:** an eligibility assessment with a gap-and-remediation list.

**Done when:** the fund's eligibility is honestly assessed and every gap has a remediation path, feeding the go/no-go (P5.T.1.4).
